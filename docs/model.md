# Model

AI Inference Lab uses YOLOv8 as the initial computer-vision model.

The model is exported to ONNX and executed using ONNX Runtime.

## Model Pipeline

```text
YOLOv8
   ↓
PyTorch Model (.pt)
   ↓
ONNX Export
   ↓
ONNX Model (.onnx)
   ↓
ONNX Runtime
   ↓
Inference


YOLOv8n

The initial model is:

YOLOv8n

The n variant is a lightweight model that allows us to establish an inference baseline before moving toward larger models and GPU acceleration.

Downloading the Model

Run:

python scripts/download_model.py

This produces:

models/yolov8n.pt

Exporting to ONNX

Run:

python scripts/export_onnx.py

This produces:

models/yolov8n.onnx
Validating the ONNX Model

Run:

python scripts/validate_onnx.py

The validation performs two checks:

Validates the ONNX model structure.
Creates an ONNX Runtime session using the CPU execution provider.

It also displays the model input and output information.

Model Input

The current model expects:

name  : images
shape : [1, 3, 640, 640]
type  : tensor(float)

The dimensions represent:

1 → Batch size
3 → RGB channels
640 → Height
640 → Width

The input tensor uses:

Layout : NCHW
Type   : float32

Therefore, our preprocessing pipeline must produce:

[1, 3, 640, 640]

Model Output

The model produces:

name  : output0
shape : [1, 84, 8400]
type  : tensor(float)

The output contains predictions for the YOLOv8 detection head.

For the COCO-trained model:

84 = 4 bounding-box values + 80 class scores

The 8400 dimension represents the candidate predictions generated by the model.

Before producing application-level detections, this output needs to go through post-processing.

Model Artifacts

Model binaries are generated locally and should not be committed to Git.

Add:

models/*.pt
models/*.onnx

to .gitignore.

The repository contains the scripts required to reproduce the model artifacts.
